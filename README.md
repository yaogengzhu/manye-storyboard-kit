## 小说转漫画的基本流程

```text
准备故事 → 整理角色 → 拆分镜头 → 确认分镜 → 生成画面 → 逐页验稿 → 导出图片 ZIP
```

1. **准备一段完整情节。** 先选一次相遇、一段冲突或一个转折，确认人物称呼和对白归属。
2. **记录角色的固定特征。** 分开写发型、服装、配饰，以及当前表情、姿态和持有物件。
3. **每镜表达一个主要动作。** 将“跑到站台、接过本子、低头看猫”等先后动作分开，避免一幅静止画面承载多个时刻。
4. **先确认分镜，再生成画面。** 检查原文是否遗漏、镜头能否衔接、对白是否由正确的人说出。
5. **逐页检查并调整。** 对有问题的画面修正描述，使用当前可用的编辑或单页重绘入口；再次生成前查看积分预估。
6. **按阅读顺序导出。** 核对缺页、重复页和当前版本，将全部可下载图片整理成一个 ZIP。

## 一个原创分镜示例：雨中站台

林遥跑回雨中的站台，发现长椅上的笔记本不见了。她停下来，低声说：“我的本子呢？”一个撑伞的年轻人把本子递过来，问她：“是在找这个吗？”林遥接过本子，松了口气：“谢谢，刚才太着急了。”椅子下的橘猫探出头叫了一声，两人一起低头看它。

角色卡：林遥是短黑发、白衬衫、黄色背包；年轻人是棕色短发、深灰外套、深蓝雨伞。笔记本为棕色。这些是本例的美术设定。

| 镜头 | 景别 | 一个主要动作 | 对白 | 连续性检查 |
| --- | --- | --- | --- | --- |
| 1 | 远景 | 林遥跑到雨中的长椅前 | 无 | 长椅空着，笔记本尚未出现 |
| 2 | 中近景 | 林遥低头看空椅面 | 林遥：“我的本子呢？” | 黄色背包和站台方向延续上一镜 |
| 3 | 双人中景 | 年轻人伸手递出本子 | 年轻人：“是在找这个吗？” | 本子仍在年轻人手里 |
| 4 | 手部近景 | 林遥接住本子，年轻人松手 | 无 | 交接同一本棕色笔记本 |
| 5 | 近景 | 林遥抱着本子抬头 | 林遥：“谢谢，刚才太着急了。” | 本子由林遥持有，服装与背包不变 |
| 6 | 低机位中景 | 橘猫从长椅下探头，两人低头看它 | 拟声：“喵” | 同一站台、同一长椅 |

六个镜头是本例的叙事拆分，不等于六张漫画页。一页可以容纳多格，实际分页按故事节奏和制作设置决定。

## 可复制的分镜字段

复制下列内容到任意文本编辑器，按自己的故事填写：

```text
镜头编号：
原文依据：
叙事目的：
景别与视角：
人物与固定特征：
画面动作：
对白与旁白（标明说话人）：
连续性检查（场景、站位、物件归属）：
```

这个文本模板用于人工规划。填写模板不会自动生成图片，也不是工作台的自动导入格式。

## 生成前后检查什么

- 每个镜头有对应原文，新增对白经过作者确认。
- 同一角色的核心特征稳定；换装、姿态变化和物件交接有剧情依据。
- 相邻镜头的场景、人物站位和物件持有人衔接清楚。
- 对白归属正确，缩小到手机阅读尺寸仍能辨认。
- 导出前核对页面顺序、缺页、重复页和最终版本。
